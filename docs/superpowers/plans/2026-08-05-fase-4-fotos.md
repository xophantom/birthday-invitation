# Fase 4 — Fotos: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Permitir que o convidado envie fotos pela rota do QR Code, com compressão no navegador e upload direto ao Vercel Blob, gravando o par full+thumbnail no banco.

**Architecture:** O navegador comprime cada foto em duas versões e as envia **direto ao Blob**, sem passar pelo servidor da aplicação — Server Actions têm limite de corpo (~4,5MB) e o convidado manda várias fotos de uma vez. O route handler apenas emite token assinado e aplica o teto global de armazenamento. O registro no banco acontece depois, por Server Action.

**Tech Stack:** @vercel/blob 2.6, browser-image-compression 2.0, heic2any 0.0.4, Drizzle, zod 4.

## Global Constraints

Valem para **todas** as tarefas:

- **Sem TDD.** Esta fase contém **um** dos três testes do projeto (cálculo de redimensionamento), escrito **depois** da implementação, porque proporção errada distorce todas as fotos em silêncio.
- **Nenhum componente importa `config/event.config.ts` diretamente.** Sempre `getEventConfig()`.
- **Cores de marca sempre em token** (`bg-surface`, `text-accent`, `text-foreground`, `text-danger`). Exceção: preto puro para sombra e escurecimento é profundidade, não cor de marca.
- **Toda Server Action que muta dados revalida a entrada no servidor.**
- **Tailwind v4:** sem `tailwind.config.js`.
- **Next.js 16:** `params`/`searchParams` são Promises; `cookies()` é assíncrono.
- **Todo texto de interface em pt-BR**, com acentuação correta.
- **Alias de import:** `@/*` → raiz do projeto.
- **Commits em pt-BR**, formato `tipo: descrição`.

- Produces:

  - `countPhotos(): Promise<number>`
  - `listPhotos(options: { limit: number; cursor?: string }): Promise<{ items: Photo[]; nextCursor: string | null }>` — usada na Fase 5
  - `togglePhotoFavorite(id: string, isFavorite: boolean): Promise<void>` — usada na Fase 5
  - `listFavoritePhotos(): Promise<Photo[]>` — usada na Fase 5

- [ ] **Step 1: Escrever as queries**

A paginação é por cursor em `created_at` e não por `offset`: com offset, fotos novas chegando durante a revisão deslocam a janela e o admin vê itens repetidos ou pula outros.

```ts
// lib/db/queries/photos.ts
import 'server-only'
import { and, desc, eq, lt } from 'drizzle-orm'
import { db, photos, type NewPhoto, type Photo } from '@/lib/db'

export async function createPhotoRecord(input: NewPhoto): Promise<Photo> {
  const [created] = await db.insert(photos).values(input).returning()
  return created
}

export async function countPhotos(): Promise<number> {
  const rows = await db.$count(photos)
  return rows
}

export async function listPhotos({
  limit,
  cursor,
}: {
  limit: number
  cursor?: string
}): Promise<{ items: Photo[]; nextCursor: string | null }> {
  const where = cursor ? lt(photos.createdAt, new Date(cursor)) : undefined

  // Busca um item a mais para saber se existe próxima página sem fazer count.
  const rows = await db
    .select()
    .from(photos)
    .where(where)
    .orderBy(desc(photos.createdAt))
    .limit(limit + 1)

  const items = rows.slice(0, limit)
  const nextCursor =
    rows.length > limit ? items[items.length - 1].createdAt.toISOString() : null

  return { items, nextCursor }
}

export async function togglePhotoFavorite(id: string, isFavorite: boolean): Promise<void> {
  await db.update(photos).set({ isFavorite }).where(eq(photos.id, id))
}

export async function listFavoritePhotos(): Promise<Photo[]> {
  return db
    .select()
    .from(photos)
    .where(eq(photos.isFavorite, true))
    .orderBy(desc(photos.createdAt))
}
```

Se `db.$count` não existir na versão instalada do Drizzle, substitua `countPhotos` por:

### Task 2: Cálculo de redimensionamento e seu teste

**Files:**

**Interfaces:**
- Consumes: nada (função pura)
- Produces: `computeTargetSize(width: number, height: number, maxSide: number): { width: number; height: number }`

- [ ] **Step 1: Escrever a função**

Isolada da lib de compressão de propósito: é a única parte da pipeline que dá para verificar sem navegador, e é onde um erro passa despercebido — a foto sai distorcida, ninguém percebe durante a festa, e o acervo inteiro fica comprometido.

```ts
// lib/photos/resize.ts

/**
 * Reduz proporcionalmente para que o maior lado caiba em `maxSide`.
 * Imagens menores que o limite são preservadas — ampliar só adiciona peso sem detalhe.
 */
export function computeTargetSize(
  width: number,
  height: number,
  maxSide: number
): { width: number; height: number } {
  const largest = Math.max(width, height)

  if (largest <= maxSide) {
    return { width, height }
  }

  const ratio = maxSide / largest

  return {
    width: Math.round(width * ratio),
    height: Math.round(height * ratio),
  }
}

export const FULL_MAX_SIDE = 2048
export const THUMB_MAX_SIDE = 400
export const FULL_QUALITY = 0.83
export const THUMB_QUALITY = 0.7
```

```ts
import { computeTargetSize, FULL_MAX_SIDE, THUMB_MAX_SIDE } from './resize'

describe('computeTargetSize', () => {
  it('preserva imagens menores que o limite', () => {
    expect(computeTargetSize(800, 600, FULL_MAX_SIDE)).toEqual({ width: 800, height: 600 })
  })

  it('reduz pelo lado maior em imagem paisagem', () => {

  })
```

- [ ] **Step 2: Escrever o handler**

Este é o único ponto do servidor no caminho do upload. Ele existe para duas coisas: assinar o token (a credencial do Blob nunca vai ao navegador) e recusar novos envios quando o armazenamento se aproxima do limite do plano.

```ts
// app/api/photos/upload/route.ts
import { handleUpload, type HandleUploadBody } from '@vercel/blob/client'
import { NextResponse } from 'next/server'
import { getEventConfig } from '@/lib/config'
import { countPhotos } from '@/lib/db/queries/photos'

const GLOBAL_LIMIT = Number(process.env.PHOTOS_GLOBAL_LIMIT ?? 1000)

export async function POST(request: Request): Promise<NextResponse> {
  const body = (await request.json()) as HandleUploadBody
  const config = getEventConfig()

  try {
    const result = await handleUpload({
      body,
      request,
      onBeforeGenerateToken: async () => {
        // Cada registro no banco representa um par full+thumb, mas o Blob conta
        // arquivos individualmente — daí o fator 2 na verificação.
        const total = await countPhotos()

        if (total >= GLOBAL_LIMIT) {
          throw new Error('Limite de armazenamento atingido.')
        }

        return {
          allowedContentTypes: ['image/jpeg'],
          addRandomSuffix: true,
          maximumSizeInBytes: config.photos.maxFileSizeMb * 1024 * 1024,
        }
      },
      onUploadCompleted: async () => {
        // Intencionalmente vazio. O registro no banco acontece em registerPhoto(),
        // porque este callback não dispara em localhost sem túnel e chega por
        // arquivo — o que quebraria o pareamento full+thumb.
      },
    })

    return NextResponse.json(result)
  } catch (error) {
    const message =
      error instanceof Error ? error.message : 'Não foi possível iniciar o envio.'
    console.error('Falha ao emitir token de upload:', error)
    return NextResponse.json({ error: message }, { status: 400 })
  }
}
```


- [ ] **Step 2: Escrever o hook**

Três detalhes que importam:

- **HEIC primeiro.** iPhone entrega HEIC por padrão, e a lib de compressão não o lê. A conversão é carregada sob demanda (`await import`) porque `heic2any` é pesado e a maioria dos envios não precisa dela.
- **Web Worker.** Comprimir oito fotos na thread principal congela a interface; `useWebWorker: true` resolve.
- **Saída sempre JPEG.** Uniformiza o acervo e evita PNG de 8MB no armazenamento.

```ts
// hooks/use-image-compression.ts
'use client'

import { useCallback } from 'react'
import imageCompression from 'browser-image-compression'
import {
  FULL_MAX_SIDE,
  FULL_QUALITY,
  THUMB_MAX_SIDE,
  THUMB_QUALITY,
} from '@/lib/photos/resize'

export type CompressedPair = {
  full: File
  thumb: File
  originalName: string
}

const HEIC_TYPES = ['image/heic', 'image/heif']

async function toJpegIfNeeded(file: File): Promise<File> {
  const isHeic =
    HEIC_TYPES.includes(file.type) || /\.hei[cf]$/i.test(file.name)

  if (!isHeic) return file

  const { default: heic2any } = await import('heic2any')
  const converted = await heic2any({ blob: file, toType: 'image/jpeg', quality: 0.9 })
  const blob = Array.isArray(converted) ? converted[0] : converted

  return new File([blob], file.name.replace(/\.hei[cf]$/i, '.jpg'), {
    type: 'image/jpeg',
  })
}

export function useImageCompression() {
  const compress = useCallback(async (file: File): Promise<CompressedPair> => {
    const source = await toJpegIfNeeded(file)

    const [full, thumb] = await Promise.all([
      imageCompression(source, {
        maxWidthOrHeight: FULL_MAX_SIDE,
        initialQuality: FULL_QUALITY,
        fileType: 'image/jpeg',
        useWebWorker: true,
      }),
      imageCompression(source, {
        maxWidthOrHeight: THUMB_MAX_SIDE,
        initialQuality: THUMB_QUALITY,
        fileType: 'image/jpeg',
        useWebWorker: true,
      }),
    ])

    return { full, thumb, originalName: source.name }
  }, [])

  return { compress }
}
```

- [ ] **Step 1: Escrever a Server Action de registro**

A validação de URL é o que impede alguém de chamar esta action por POST direto e poluir o banco com endereços arbitrários. Não é defesa perfeita — é proporcional: o pior caso restante é um registro apontando para um blob real do próprio store.

```ts
// app/(site)/fotos/actions.ts
'use server'

import { revalidatePath } from 'next/cache'
import { z } from 'zod'
import { createPhotoRecord } from '@/lib/db/queries/photos'

const blobUrl = z
  .string()
  .url()
  .refine(
    (value) => /^https:\/\/[a-z0-9-]+\.public\.blob\.vercel-storage\.com\/photos\//.test(value),
    { error: 'URL fora do armazenamento esperado.' }
  )

const registerPhotoSchema = z.object({
  fullUrl: blobUrl,
  thumbUrl: blobUrl,
  fullPathname: z.string().min(1),
  thumbPathname: z.string().min(1),
  uploadedBy: z.string().trim().max(120).nullable(),
})

export async function registerPhoto(input: unknown) {
  const parsed = registerPhotoSchema.safeParse(input)

  if (!parsed.success) {
    console.error('registerPhoto recebeu payload inválido:', z.treeifyError(parsed.error))
    return { ok: false, message: 'Não foi possível registrar a foto.' }
  }

  try {
    await createPhotoRecord(parsed.data)
  } catch (error) {
    console.error('Falha ao registrar foto:', error)
    return { ok: false, message: 'Não foi possível registrar a foto.' }
  }

  revalidatePath('/admin/fotos')

  return { ok: true }
}
```

- [ ] **Step 2: Escrever o hook de upload**

O estado é por foto, não global: se sete de oito subiram, o convidado precisa reenviar só a que falhou — obrigá-lo a repetir tudo é a diferença entre ter as fotos e não ter.

```ts
// hooks/use-photo-upload.ts
'use client'

import { upload } from '@vercel/blob/client'
import { useCallback, useState } from 'react'
import { registerPhoto } from '@/app/(site)/fotos/actions'
import { useImageCompression } from '@/hooks/use-image-compression'

export type UploadStatus = 'pending' | 'compressing' | 'uploading' | 'done' | 'error'

export type UploadItem = {
  id: string
  name: string
  file: File
  status: UploadStatus
  error?: string
}

export function usePhotoUpload(uploaderName: string | null) {
  const { compress } = useImageCompression()
  const [items, setItems] = useState<UploadItem[]>([])

  const update = useCallback((id: string, patch: Partial<UploadItem>) => {
    setItems((current) =>
      current.map((item) => (item.id === id ? { ...item, ...patch } : item))
    )
  }, [])

  const addFiles = useCallback((files: File[]) => {
    setItems(
      files.map((file, index) => ({
        id: `${index}-${file.name}`,
        name: file.name,
        file,
        status: 'pending' as const,
      }))
    )
  }, [])

  const uploadOne = useCallback(
    async (item: UploadItem) => {
      try {
        update(item.id, { status: 'compressing', error: undefined })
        const pair = await compress(item.file)

        update(item.id, { status: 'uploading' })
        const stamp = `${Date.now()}-${item.id}`

        const [fullBlob, thumbBlob] = await Promise.all([
          upload(`photos/${stamp}-full.jpg`, pair.full, {
            access: 'public',
            handleUploadUrl: '/api/photos/upload',
          }),
          upload(`photos/${stamp}-thumb.jpg`, pair.thumb, {
            access: 'public',
            handleUploadUrl: '/api/photos/upload',
          }),
        ])

        const result = await registerPhoto({
          fullUrl: fullBlob.url,
          thumbUrl: thumbBlob.url,
          fullPathname: fullBlob.pathname,
          thumbPathname: thumbBlob.pathname,
          uploadedBy: uploaderName?.trim() || null,
        })

        if (!result.ok) throw new Error(result.message)

        update(item.id, { status: 'done' })
      } catch (error) {
        console.error('Falha no envio da foto:', error)
        update(item.id, {
          status: 'error',
          error:
            error instanceof Error
              ? error.message
              : 'Não conseguimos enviar esta foto.',
        })
      }
    },
    [compress, uploaderName, update]
  )

  const uploadAll = useCallback(async () => {
    // Sequencial de propósito: conexão de festa é ruim, e paralelizar
    // oito uploads costuma derrubar todos em vez de acelerar.
    for (const item of items) {
      if (item.status === 'done') continue
      await uploadOne(item)
    }
  }, [items, uploadOne])

  const retry = useCallback(
    async (id: string) => {
      const item = items.find((candidate) => candidate.id === id)
      if (item) await uploadOne(item)
    },
    [items, uploadOne]
  )

  const reset = useCallback(() => setItems([]), [])

  return { items, addFiles, uploadAll, retry, reset }
}
```

Decisões de interface que vêm do contexto de uso — convidado de pé, no escuro, com pressa:

```tsx
// app/(site)/fotos/PhotoUploader.tsx
'use client'

import { useState, type ChangeEvent } from 'react'
import { Button } from '@/components/ui/Button'
import { Card } from '@/components/ui/Card'
import { FormField } from '@/components/ui/FormField'
import { usePhotoUpload } from '@/hooks/use-photo-upload'

const statusLabel: Record<string, string> = {
  pending: 'Na fila',
  compressing: 'Preparando...',
  uploading: 'Enviando...',
  done: 'Enviada',
  error: 'Falhou',
}

type PhotoUploaderProps = {
  maxPerUpload: number
  maxFileSizeMb: number
}

export function PhotoUploader({ maxPerUpload, maxFileSizeMb }: PhotoUploaderProps) {
  const [name, setName] = useState('')
  const [inputError, setInputError] = useState<string | null>(null)
  const [busy, setBusy] = useState(false)
  const { items, addFiles, uploadAll, retry, reset } = usePhotoUpload(name)

  function handleSelect(event: ChangeEvent<HTMLInputElement>) {
    const files = Array.from(event.target.files ?? [])
    setInputError(null)

    if (files.length > maxPerUpload) {
      setInputError(`Envie no máximo ${maxPerUpload} fotos por vez.`)
      return
    }

    const tooBig = files.find((file) => file.size > maxFileSizeMb * 1024 * 1024)
    if (tooBig) {
      setInputError(`"${tooBig.name}" passa de ${maxFileSizeMb}MB.`)
      return
    }

    const notImage = files.find((file) => !file.type.startsWith('image/'))
    if (notImage) {
      setInputError(`"${notImage.name}" não é uma imagem.`)
      return
    }

    addFiles(files)
  }

  async function handleSend() {
    setBusy(true)
    await uploadAll()
    setBusy(false)
  }

  const allDone = items.length > 0 && items.every((item) => item.status === 'done')

  return (
    <div className="flex flex-col gap-6">
      <FormField
        label="Seu nome"
        htmlFor="uploaderName"
        optional
        hint="Assim sabemos de quem veio a foto — mas pode pular."
      >
        <input
          id="uploaderName"
          value={name}
          onChange={(event) => setName(event.target.value)}
          autoComplete="name"
          className="min-h-11 w-full rounded-xl border border-accent/30 bg-surface-deep/60 px-4 text-foreground placeholder:text-foreground/40"
        />
      </FormField>

      <div>
        <label
          htmlFor="photos"
          className="flex min-h-30 cursor-pointer flex-col items-center justify-center gap-2 rounded-2xl border-2 border-dashed border-accent/40 px-6 text-center transition-colors hover:border-accent"
        >
          <span aria-hidden className="text-3xl text-accent">
            ✦
          </span>
          <span className="text-foreground">Toque para escolher as fotos</span>
          <span className="text-xs text-foreground/60">
            Até {maxPerUpload} por vez, {maxFileSizeMb}MB cada
          </span>
        </label>
        <input
          id="photos"
          type="file"
          accept="image/*"
          multiple
          onChange={handleSelect}
          className="sr-only"
        />
      </div>

      {inputError && (
        <p role="alert" className="text-sm text-danger">
          {inputError}
        </p>
      )}

      {items.length > 0 && (
        <Card>
          <ul className="flex flex-col gap-3">
            {items.map((item) => (
              <li key={item.id} className="flex items-center justify-between gap-3">
                <span className="truncate text-sm text-foreground/90">{item.name}</span>
                <span className="flex shrink-0 items-center gap-2">
                  <span
                    className={
                      item.status === 'error'
                        ? 'text-xs text-danger'
                        : item.status === 'done'
                          ? 'text-xs text-highlight'
                          : 'text-xs text-foreground/60'
                    }
                  >
                    {statusLabel[item.status]}
                  </span>
                  {item.status === 'error' && (
                    <button
                      type="button"
                      onClick={() => retry(item.id)}
                      className="text-xs text-accent-light underline underline-offset-4"
                    >
                      Tentar de novo
                    </button>
                  )}
                </span>
              </li>
            ))}
          </ul>
        </Card>
      )}

      {allDone ? (
        <div className="flex flex-col gap-3 text-center">
          <p className="font-display text-2xl text-accent-light">Fotos enviadas. Obrigado!</p>
          <Button variant="ghost" onClick={reset}>
            Enviar mais fotos
          </Button>
        </div>
      ) : (
        items.length > 0 && (
          <Button size="lg" onClick={handleSend} disabled={busy}>
            {busy ? 'Enviando...' : `Enviar ${items.length} foto(s)`}
          </Button>
        )
      )}
    </div>
  )
}
```
