# Fase 3 — RSVP: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Conectar o convite ao Neon e substituir a casca de `/confirmar` por um formulário de RSVP funcional, gravando confirmações no banco.

**Architecture:** Drizzle sobre o driver serverless do Neon. Um único schema zod é a fonte de verdade da validação, usado pelo `react-hook-form` no cliente e revalidado dentro da Server Action — obrigatório, porque Server Actions são alcançáveis por POST direto, fora da UI.

**Tech Stack:** Drizzle ORM 0.45, drizzle-kit 0.31, @neondatabase/serverless 1.1, zod 4, react-hook-form 7, Vitest 4.

## Global Constraints

Valem para **todas** as tarefas:

- **Sem TDD.** O `tmp/prompt.md` proíbe escrever teste antes da implementação e cobertura ampla. Esta fase contém **um** dos três testes do projeto inteiro (validação do schema de RSVP nos limites), escrito **depois** da implementação, porque um schema errado aceita lixo em silêncio.
- **Nenhum componente importa `config/event.config.ts` diretamente.** Sempre `getEventConfig()`.
- **Nenhuma cor literal em componente.** Sempre token.
- **Toda Server Action que muta dados revalida a entrada no servidor**, independentemente da validação de cliente.
- **Tailwind v4:** sem `tailwind.config.js`.
- **Next.js 16:** `params`/`searchParams` são Promises; `cookies()` é assíncrono.
- **Todo texto de interface em pt-BR**, com acentuação correta.
- **Alias de import:** `@/*` → raiz do projeto.
- **Commits em pt-BR**, formato `tipo: descrição`.

- [ ] **Step 2: Criar o schema**

As duas tabelas entram juntas: a de fotos é usada na Fase 4, e gerar duas migrações separadas para um banco novo não traz benefício.

Duas diferenças em relação ao mapeamento original, ambas decididas no design: `isFavorite` no lugar de `status pending/approved/rejected` (não existe mural público, então três estados não controlavam visibilidade de nada), e os `pathname` guardados junto das URLs — sem eles não há como apagar um blob depois.

```ts
// lib/db/schema.ts
import {
  boolean,
  index,
  integer,
  pgEnum,
  pgTable,
  text,
  timestamp,
  uuid,
} from 'drizzle-orm/pg-core'

export const rsvpSource = pgEnum('rsvp_source', ['guest', 'admin'])
export const rsvpStatus = pgEnum('rsvp_status', ['confirmed', 'removed'])

export const rsvps = pgTable(
  'rsvps',
  {
    id: uuid('id').primaryKey().defaultRandom(),
    fullName: text('full_name').notNull(),
    phone: text('phone'),
    companionsCount: integer('companions_count').notNull().default(0),
    message: text('message'),
    source: rsvpSource('source').notNull().default('guest'),
    status: rsvpStatus('status').notNull().default('confirmed'),
    createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
    updatedAt: timestamp('updated_at', { withTimezone: true }).notNull().defaultNow(),
  },
  (table) => [index('idx_rsvps_status').on(table.status)]
)

export const photos = pgTable(
  'photos',
  {
    id: uuid('id').primaryKey().defaultRandom(),
    fullUrl: text('full_url').notNull(),
    thumbUrl: text('thumb_url').notNull(),
    fullPathname: text('full_pathname').notNull(),
    thumbPathname: text('thumb_pathname').notNull(),
    uploadedBy: text('uploaded_by'),
    isFavorite: boolean('is_favorite').notNull().default(false),
    createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
  },
  (table) => [index('idx_photos_created_at').on(table.createdAt)]
)

export type Rsvp = typeof rsvps.$inferSelect
export type NewRsvp = typeof rsvps.$inferInsert
export type Photo = typeof photos.$inferSelect
export type NewPhoto = typeof photos.$inferInsert
```

- [ ] **Step 1: Escrever o schema**

Um único schema para os dois lados. Só `fullName` é obrigatório — o resto é opcional por decisão de produto, e campo obrigatório demais derruba confirmação.

`z.coerce.number()` no contador de acompanhantes porque `FormData` e inputs HTML entregam string.

```ts
// lib/validation/rsvp.ts
import { z } from 'zod'

export const rsvpFormSchema = z.object({
  fullName: z
    .string()
    .trim()
    .min(3, { error: 'Informe seu nome completo.' })
    .max(120, { error: 'Nome muito longo.' }),
  phone: z
    .string()
    .trim()
    .max(20, { error: 'Telefone muito longo.' })
    .optional()
    .or(z.literal('')),
  companionsCount: z.coerce
    .number({ error: 'Informe um número.' })
    .int({ error: 'Informe um número inteiro.' })
    .min(0, { error: 'Não pode ser negativo.' })
    .max(20, { error: 'No máximo 20 acompanhantes.' })
    .default(0),
  message: z
    .string()
    .trim()
    .max(500, { error: 'Recado muito longo.' })
    .optional()
    .or(z.literal('')),
})

export type RsvpFormValues = z.infer<typeof rsvpFormSchema>
```

### Task 3: Camada de acesso a dados

**Files:**
- Create: `lib/db/queries/rsvp.ts`

**Interfaces:**
- Consumes: `db`, `rsvps` (Task 1), `RsvpFormValues` (Task 2)
- Produces:
  - `createRsvpRecord(values: RsvpFormValues, source: 'guest' | 'admin'): Promise<Rsvp>`
  - `listRsvps(): Promise<Rsvp[]>` — usada pelo admin na Fase 5
  - `removeRsvp(id: string): Promise<void>` — usada pelo admin na Fase 5
  - `countConfirmedGuests(): Promise<{ confirmations: number; people: number }>`

- [ ] **Step 1: Escrever as queries**

Nenhuma outra camada fala com a tabela diretamente. Strings vazias viram `null` aqui, na fronteira — deixar `''` no banco significaria checar dois valores para "sem telefone" em todo lugar depois.

```ts
// lib/db/queries/rsvp.ts
import 'server-only'
import { desc, eq, sql } from 'drizzle-orm'
import { db, rsvps, type Rsvp } from '@/lib/db'
import type { RsvpFormValues } from '@/lib/validation/rsvp'

function emptyToNull(value: string | undefined) {
  const trimmed = value?.trim()
  return trimmed ? trimmed : null
}

export async function createRsvpRecord(
  values: RsvpFormValues,
  source: 'guest' | 'admin'
): Promise<Rsvp> {
  const [created] = await db
    .insert(rsvps)
    .values({
      fullName: values.fullName.trim(),
      phone: emptyToNull(values.phone),
      companionsCount: values.companionsCount,
      message: emptyToNull(values.message),
      source,
    })
    .returning()

  return created
}

export async function listRsvps(): Promise<Rsvp[]> {
  return db
    .select()
    .from(rsvps)
    .where(eq(rsvps.status, 'confirmed'))
    .orderBy(desc(rsvps.createdAt))
}

export async function removeRsvp(id: string): Promise<void> {
  // Soft delete: preserva o histórico de quem havia confirmado.
  await db
    .update(rsvps)
    .set({ status: 'removed', updatedAt: new Date() })
    .where(eq(rsvps.id, id))
}

export async function countConfirmedGuests() {
  const [row] = await db
    .select({
      confirmations: sql<number>`count(*)::int`,
      people: sql<number>`(count(*) + coalesce(sum(${rsvps.companionsCount}), 0))::int`,
    })
    .from(rsvps)
    .where(eq(rsvps.status, 'confirmed'))

  return row ?? { confirmations: 0, people: 0 }
}
```

`people` soma confirmados **mais** acompanhantes: quem confirma também vai à festa, e esse é o número que importa para o buffet.

### Task 4: Server Action

**Files:**
- Create: `app/(site)/confirmar/actions.ts`

**Interfaces:**
- Consumes: `rsvpFormSchema` (Task 2), `createRsvpRecord` (Task 3)
- Produces: `createRsvp(values: unknown): Promise<RsvpActionResult>` onde

```ts
type RsvpActionResult =
  | { ok: true }
  | { ok: false; message: string; fieldErrors?: Record<string, string[]> }
```

- [ ] **Step 1: Escrever a action**

A revalidação no servidor não é redundância: esta função aceita POST direto, sem passar pela UI. Confiar na validação de cliente aqui significaria aceitar qualquer payload.

```ts
// app/(site)/confirmar/actions.ts
'use server'

import { revalidatePath } from 'next/cache'
import { z } from 'zod'
import { createRsvpRecord } from '@/lib/db/queries/rsvp'
import { rsvpFormSchema } from '@/lib/validation/rsvp'

export type RsvpActionResult =
  | { ok: true }
  | { ok: false; message: string; fieldErrors?: Record<string, string[]> }

export async function createRsvp(values: unknown): Promise<RsvpActionResult> {
  const parsed = rsvpFormSchema.safeParse(values)

  if (!parsed.success) {
    return {
      ok: false,
      message: 'Confira os campos destacados.',
      fieldErrors: z.flattenError(parsed.error).fieldErrors as Record<string, string[]>,
    }
  }

  try {
    await createRsvpRecord(parsed.data, 'guest')
  } catch (error) {
    console.error('Falha ao gravar RSVP:', error)
    return {
      ok: false,
      message: 'Não conseguimos registrar sua confirmação. Tente novamente em instantes.',
    }
  }

  // Mantém a lista do admin (Fase 5) atualizada assim que alguém confirma.
  revalidatePath('/admin')

  return { ok: true }
}
```

- [ ] **Step 2: Escrever o hook**

Isola a lógica da apresentação: o componente cuida de marcação e estilo, o hook cuida de estado, validação e submissão.

```ts
// hooks/use-rsvp-form.ts
'use client'

import { zodResolver } from '@hookform/resolvers/zod'
import { useState } from 'react'
import { useForm } from 'react-hook-form'
import { createRsvp } from '@/app/(site)/confirmar/actions'
import { rsvpFormSchema, type RsvpFormValues } from '@/lib/validation/rsvp'

export function useRsvpForm() {
  const [submitted, setSubmitted] = useState(false)
  const [serverError, setServerError] = useState<string | null>(null)

  const form = useForm<RsvpFormValues>({
    resolver: zodResolver(rsvpFormSchema),
    defaultValues: {
      fullName: '',
      phone: '',
      companionsCount: 0,
      message: '',
    },
  })

  const onSubmit = form.handleSubmit(async (values) => {
    setServerError(null)
    const result = await createRsvp(values)

    if (result.ok) {
      setSubmitted(true)
      return
    }

    setServerError(result.message)

    for (const [field, messages] of Object.entries(result.fieldErrors ?? {})) {
      if (messages?.[0]) {
        form.setError(field as keyof RsvpFormValues, { message: messages[0] })
      }
    }
  })

  return { form, onSubmit, submitted, serverError }
}
```

- [ ] **Step 3: Escrever o formulário**

O `isSubmitting` desabilita o botão — sem isso, um toque duplo no celular grava duas confirmações.

```tsx
// app/(site)/confirmar/RsvpForm.tsx
'use client'

import { Button } from '@/components/ui/Button'
import { Card } from '@/components/ui/Card'
import { FormField } from '@/components/ui/FormField'
import { useRsvpForm } from '@/hooks/use-rsvp-form'

const inputClass =
  'min-h-11 w-full rounded-xl border border-ouro/30 bg-esmeralda-fundo/60 px-4 text-creme placeholder:text-creme/40'

export function RsvpForm() {
  const { form, onSubmit, submitted, serverError } = useRsvpForm()
  const { errors, isSubmitting } = form.formState

  if (submitted) {
    return (
      <Card className="text-center">
        <p className="font-display text-3xl text-ouro-claro">Presença confirmada!</p>
        <p className="mt-3 text-creme/85">
          Que alegria ter você conosco. Nos vemos na festa.
        </p>
      </Card>
    )
  }

  return (
    <form onSubmit={onSubmit} noValidate className="flex flex-col gap-5">
      <FormField label="Nome completo" htmlFor="fullName" error={errors.fullName?.message}>
        <input
          id="fullName"
          autoComplete="name"
          className={inputClass}
          {...form.register('fullName')}
        />
      </FormField>

      <FormField label="Telefone" htmlFor="phone" optional error={errors.phone?.message}>
        <input
          id="phone"
          type="tel"
          inputMode="tel"
          autoComplete="tel"
          className={inputClass}
          {...form.register('phone')}
        />
      </FormField>

      <FormField
        label="Número de acompanhantes"
        htmlFor="companionsCount"
        optional
        hint="Quantas pessoas vêm com você, sem contar você."
        error={errors.companionsCount?.message}
      >
        <input
          id="companionsCount"
          type="number"
          min={0}
          max={20}
          inputMode="numeric"
          className={inputClass}
          {...form.register('companionsCount')}
        />
      </FormField>

      <FormField label="Recado" htmlFor="message" optional error={errors.message?.message}>
        <textarea
          id="message"
          rows={4}
          placeholder="Tem alguma restrição alimentar? Quer deixar alguma coisa avisada? Deixe o recado aqui."
          className={`${inputClass} min-h-30 py-3`}
          {...form.register('message')}
        />
      </FormField>

      {serverError && (
        <p role="alert" className="text-sm text-red-300">
          {serverError}
        </p>
      )}

      <Button type="submit" size="lg" disabled={isSubmitting}>
        {isSubmitting ? 'Enviando...' : 'Confirmar presença'}
      </Button>
    </form>
  )
}
```
