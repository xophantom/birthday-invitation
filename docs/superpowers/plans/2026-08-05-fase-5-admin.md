# Fase 5 — Admin: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar a área protegida onde o anfitrião gerencia confirmações e revisa as fotos privadas dos convidados.

**Architecture:** Sessão stateless em JWT assinado (jose), guardado em cookie httpOnly. A verificação real acontece numa camada de acesso a dados memoizada, chamada pelo layout do admin, por cada página e **dentro de cada Server Action** — o `proxy.ts` faz apenas redirect otimista, porque o próprio doc do Next 16 diz que proxy não é solução de autorização. O download em lote é montado no navegador.

**Tech Stack:** jose 6, Drizzle, client-zip 2.5, Vitest 4.

## Global Constraints

Valem para **todas** as tarefas:

- **Sem TDD.** Esta fase contém **um** dos três testes do projeto (assinatura e verificação da sessão), escrito **depois** da implementação, porque uma verificação quebrada abre o `/admin` para qualquer pessoa sem nenhum sintoma visível.
- **Toda página e toda Server Action do admin chama `requireAdmin()` antes de qualquer outra coisa.** Server Actions são alcançáveis por POST direto; confiar no layout ou no proxy deixa a porta aberta.
- **Nenhum componente importa `config/event.config.ts` diretamente.** Sempre `getEventConfig()`.
- **Cores de marca sempre em token** (`bg-surface`, `text-accent`, `text-foreground`, `text-danger`). Exceção: preto puro para sombra e escurecimento é profundidade, não cor de marca.
- **Tailwind v4:** sem `tailwind.config.js`.
- **Next.js 16:** `middleware.ts` não existe — o arquivo é `proxy.ts` na raiz. `cookies()` é assíncrono.
- **Todo texto de interface em pt-BR**, com acentuação correta.
- **Alias de import:** `@/*` → raiz do projeto.
- **Commits em pt-BR**, formato `tipo: descrição`.

- [ ] **Step 2: Escrever as funções puras**

Separadas de cookies e de `process.env` de propósito: é o que permite testá-las sem simular requisição, e é a única parte do fluxo de autenticação onde um erro é invisível.

O payload é deliberadamente vazio — há um único operador, e não existe informação de usuário que valha a pena carregar num token que trafega em cookie.

```ts
// lib/auth/token.ts
import { SignJWT, jwtVerify } from 'jose'

const ALGORITHM = 'HS256'
const AUDIENCE = 'convite-admin'

function toKey(secret: string): Uint8Array {
  return new TextEncoder().encode(secret)
}

export async function signSession(
  secret: string,
  expiresInSeconds = 60 * 60 * 24 * 7
): Promise<string> {
  return new SignJWT({})
    .setProtectedHeader({ alg: ALGORITHM })
    .setAudience(AUDIENCE)
    .setIssuedAt()
    .setExpirationTime(`${expiresInSeconds}s`)
    .sign(toKey(secret))
}

export async function verifySessionToken(
  token: string | undefined,
  secret: string
): Promise<boolean> {
  if (!token) return false

  try {
    await jwtVerify(token, toKey(secret), {
      algorithms: [ALGORITHM],
      audience: AUDIENCE,
    })
    return true
  } catch {
    return false
  }
}
```

O terceiro e último teste do projeto. Cobre o que precisa ser verdade para o admin não vazar: token válido passa, token de outra chave não passa, token adulterado não passa, token expirado não passa.

```ts
// lib/auth/token.test.ts
import { describe, expect, it } from 'vitest'
import { signSession, verifySessionToken } from './token'

const SECRET = 'segredo-de-teste-com-tamanho-suficiente-1234567890'
const OTHER_SECRET = 'outro-segredo-completamente-diferente-0987654321'

describe('sessão do admin', () => {
  it('aceita um token que ela mesma assinou', async () => {
    const token = await signSession(SECRET)

    await expect(verifySessionToken(token, SECRET)).resolves.toBe(true)
  })

  it('rejeita token assinado com outra chave', async () => {
    const token = await signSession(OTHER_SECRET)

    await expect(verifySessionToken(token, SECRET)).resolves.toBe(false)
  })

  it('rejeita token adulterado', async () => {
    const token = await signSession(SECRET)
    const tampered = `${token.slice(0, -4)}aaaa`

    await expect(verifySessionToken(tampered, SECRET)).resolves.toBe(false)
  })

  it('rejeita token expirado', async () => {
    const token = await signSession(SECRET, -10)

    await expect(verifySessionToken(token, SECRET)).resolves.toBe(false)
  })

  it('rejeita ausência de token', async () => {
    await expect(verifySessionToken(undefined, SECRET)).resolves.toBe(false)
  })
})
```

- [ ] **Step 1: Escrever a camada de sessão**

`cache()` do React memoiza a verificação dentro de um mesmo render: o layout, a página e os componentes chamam `requireAdmin()` sem custo repetido.

A comparação de senha é feita sobre digests SHA-256 de tamanho fixo com `timingSafeEqual` — comparar strings com `===` vaza, pelo tempo de resposta, quantos caracteres iniciais estão certos.

```ts
// lib/auth/session.ts
import 'server-only'
import { createHash, timingSafeEqual } from 'node:crypto'
import { cookies } from 'next/headers'
import { redirect } from 'next/navigation'
import { cache } from 'react'
import { signSession, verifySessionToken } from './token'

export const SESSION_COOKIE = 'convite_admin'

const SESSION_MAX_AGE = 60 * 60 * 24 * 7

function requiredEnv(name: 'ADMIN_PASSWORD' | 'SESSION_SECRET'): string {
  const value = process.env[name]
  if (!value) throw new Error(`${name} não definida.`)
  return value
}

export function verifyPassword(candidate: string): boolean {
  const expected = createHash('sha256').update(requiredEnv('ADMIN_PASSWORD')).digest()
  const received = createHash('sha256').update(candidate).digest()

  return timingSafeEqual(expected, received)
}

export async function createAdminSession(): Promise<void> {
  const token = await signSession(requiredEnv('SESSION_SECRET'), SESSION_MAX_AGE)
  const cookieStore = await cookies()

  cookieStore.set(SESSION_COOKIE, token, {
    httpOnly: true,
    secure: process.env.NODE_ENV === 'production',
    sameSite: 'lax',
    path: '/',
    maxAge: SESSION_MAX_AGE,
  })
}

export async function destroyAdminSession(): Promise<void> {
  const cookieStore = await cookies()
  cookieStore.delete(SESSION_COOKIE)
}

export const isAdminAuthenticated = cache(async (): Promise<boolean> => {
  const cookieStore = await cookies()
  const token = cookieStore.get(SESSION_COOKIE)?.value

  return verifySessionToken(token, requiredEnv('SESSION_SECRET'))
})

export async function requireAdmin(): Promise<void> {
  const authenticated = await isAdminAuthenticated()
  if (!authenticated) redirect('/login')
}
```

- [ ] **Step 2: Escrever o proxy**

Redirect otimista apenas: ele olha a **presença** do cookie, não sua validade. A verificação criptográfica acontece em `requireAdmin()`. O doc do Next 16 é explícito ao dizer que proxy não deve ser a autorização.

```ts
// proxy.ts
import { NextResponse } from 'next/server'
import type { NextRequest } from 'next/server'

const SESSION_COOKIE = 'convite_admin'

export function proxy(request: NextRequest) {
  const hasCookie = Boolean(request.cookies.get(SESSION_COOKIE)?.value)

  if (!hasCookie) {
    return NextResponse.redirect(new URL('/login', request.url))
  }

  return NextResponse.next()
}

export const config = {
  matcher: '/admin/:path*',
}
```

- [ ] **Step 1: Escrever a action**

O `redirect` fica **fora** do `try`: ele funciona lançando uma exceção de controle de fluxo do framework, que um `catch` engoliria.

```ts
// app/(admin)/login/actions.ts
'use server'

import { redirect } from 'next/navigation'
import { createAdminSession, verifyPassword } from '@/lib/auth/session'

export type LoginState = { error?: string }

export async function signIn(
  _state: LoginState,
  formData: FormData
): Promise<LoginState> {
  const password = String(formData.get('password') ?? '')

  if (!password) {
    return { error: 'Informe a senha.' }
  }

  let valid = false
  try {
    valid = verifyPassword(password)
  } catch (error) {
    console.error('Falha ao verificar senha:', error)
    return { error: 'Configuração de acesso indisponível.' }
  }

  if (!valid) {
    return { error: 'Senha incorreta.' }
  }

  await createAdminSession()
  redirect('/admin')
}
```

- [ ] **Step 2: Escrever as actions**

Cada uma revalida a sessão. Não é redundância com o layout: estas funções aceitam POST direto, sem passar por ele.

```ts
// app/(admin)/admin/actions.ts
'use server'

import { revalidatePath } from 'next/cache'
import { redirect } from 'next/navigation'
import { z } from 'zod'
import { destroyAdminSession, requireAdmin } from '@/lib/auth/session'
import { createRsvpRecord, removeRsvp } from '@/lib/db/queries/rsvp'
import { rsvpFormSchema } from '@/lib/validation/rsvp'

export type AdminActionResult = { ok: boolean; message?: string }

export async function addManualRsvp(
  _state: AdminActionResult,
  formData: FormData
): Promise<AdminActionResult> {
  await requireAdmin()

  const parsed = rsvpFormSchema.safeParse({
    fullName: formData.get('fullName'),
    phone: formData.get('phone') ?? '',
    companionsCount: formData.get('companionsCount') ?? 0,
    message: formData.get('message') ?? '',
  })

  if (!parsed.success) {
    const flat = z.flattenError(parsed.error).fieldErrors
    return { ok: false, message: flat.fullName?.[0] ?? 'Confira os dados informados.' }
  }

  try {
    await createRsvpRecord(parsed.data, 'admin')
  } catch (error) {
    console.error('Falha ao adicionar confirmação manual:', error)
    return { ok: false, message: 'Não foi possível adicionar.' }
  }

  revalidatePath('/admin')
  return { ok: true }
}

export async function deleteRsvp(formData: FormData): Promise<void> {
  await requireAdmin()

  const id = String(formData.get('id') ?? '')
  if (!id) return

  await removeRsvp(id)
  revalidatePath('/admin')
}

export async function signOut(): Promise<void> {
  await destroyAdminSession()
  redirect('/login')
}
```

- [ ] **Step 3: Escrever a tabela**

Nomes repetidos ficam destacados em vez de bloqueados: dois convidados podem genuinamente ter o mesmo nome, e impedir a segunda confirmação criaria o pior erro possível — o convidado real que não consegue confirmar.

```tsx
// app/(admin)/admin/GuestTable.tsx
import type { Rsvp } from '@/lib/db'
import { deleteRsvp } from './actions'

export function GuestTable({ guests }: { guests: Rsvp[] }) {
  const counts = new Map<string, number>()
  for (const guest of guests) {
    const key = guest.fullName.trim().toLowerCase()
    counts.set(key, (counts.get(key) ?? 0) + 1)
  }

  if (guests.length === 0) {
    return <p className="text-foreground/60">Nenhuma confirmação ainda.</p>
  }

  return (
    <div className="overflow-x-auto">
      <table className="w-full min-w-[46rem] border-collapse text-sm">
        <thead>
          <tr className="border-b border-accent/20 text-left text-foreground/60">
            <th className="py-3 pr-4 font-medium">Nome</th>
            <th className="py-3 pr-4 font-medium">Telefone</th>
            <th className="py-3 pr-4 font-medium">Acomp.</th>
            <th className="py-3 pr-4 font-medium">Recado</th>
            <th className="py-3 pr-4 font-medium">Origem</th>
            <th className="py-3" />
          </tr>
        </thead>
        <tbody>
          {guests.map((guest) => {
            const duplicated = (counts.get(guest.fullName.trim().toLowerCase()) ?? 0) > 1

            return (
              <tr key={guest.id} className="border-b border-accent/10 align-top">
                <td className="py-3 pr-4">
                  {guest.fullName}
                  {duplicated && (
                    <span
                      title="Existe outra confirmação com este mesmo nome"
                      className="ml-2 rounded-full bg-accent/20 px-2 py-0.5 text-xs text-accent-light"
                    >
                      nome repetido
                    </span>
                  )}
                </td>
                <td className="py-3 pr-4 text-foreground/80">{guest.phone ?? '—'}</td>
                <td className="py-3 pr-4 text-foreground/80">{guest.companionsCount}</td>
                <td className="py-3 pr-4 text-foreground/80">{guest.message ?? '—'}</td>
                <td className="py-3 pr-4">
                  <span className="rounded-full border border-accent/30 px-2 py-0.5 text-xs text-foreground/70">
                    {guest.source === 'admin' ? 'manual' : 'convidado'}
                  </span>
                </td>
                <td className="py-3">
                  <form action={deleteRsvp}>
                    <input type="hidden" name="id" value={guest.id} />
                    <button
                      type="submit"
                      className="text-xs text-danger underline underline-offset-4 hover:text-danger/80"
                    >
                      Remover
                    </button>
                  </form>
                </td>
              </tr>
            )
          })}
        </tbody>
      </table>
    </div>
  )
}
```

```tsx
// app/(admin)/admin/fotos/PhotoReviewGrid.tsx
'use client'

import { useState, useTransition } from 'react'
import { setFavorite } from './actions'
import { Modal } from '@/components/ui/Modal'
import type { Photo } from '@/lib/db'

export function PhotoReviewGrid({ photos }: { photos: Photo[] }) {
  const [opened, setOpened] = useState<Photo | null>(null)
  const [favorites, setFavorites] = useState<Record<string, boolean>>(
    Object.fromEntries(photos.map((photo) => [photo.id, photo.isFavorite]))
  )
  const [, startTransition] = useTransition()

  function toggle(photo: Photo) {
    const next = !favorites[photo.id]
    setFavorites((current) => ({ ...current, [photo.id]: next }))
    startTransition(async () => {
      await setFavorite(photo.id, next)
    })
  }

  if (photos.length === 0) {
    return <p className="text-foreground/60">Nenhuma foto enviada ainda.</p>
  }

  return (
    <>
      <ul className="grid grid-cols-2 gap-3 sm:grid-cols-3 lg:grid-cols-4">
        {photos.map((photo) => (
          <li key={photo.id} className="relative">
            <button
              type="button"
              onClick={() => setOpened(photo)}
              className="block w-full overflow-hidden rounded-xl border border-accent/20"
            >
              {/* eslint-disable-next-line @next/next/no-img-element */}
              <img
                src={photo.thumbUrl}
                alt={
                  photo.uploadedBy
                    ? `Foto enviada por ${photo.uploadedBy}`
                    : 'Foto enviada por um convidado'
                }
                loading="lazy"
                className="aspect-square w-full object-cover"
              />
            </button>

            <button
              type="button"
              onClick={() => toggle(photo)}
              aria-pressed={favorites[photo.id]}
              aria-label={
                favorites[photo.id] ? 'Remover das favoritas' : 'Marcar como favorita'
              }
              className="absolute right-2 top-2 flex h-9 w-9 items-center justify-center rounded-full bg-black/60 text-lg"
            >
              {favorites[photo.id] ? '★' : '☆'}
            </button>
          </li>
        ))}
      </ul>

      <Modal
        open={opened !== null}
        onClose={() => setOpened(null)}
        title="Foto ampliada"
      >
        {opened && (
          <figure className="flex flex-col gap-3">
            {/* eslint-disable-next-line @next/next/no-img-element */}
            <img
              src={opened.fullUrl}
              alt=""
              className="max-h-[75dvh] w-full rounded-xl object-contain"
            />
            <figcaption className="flex items-center justify-between text-sm text-foreground/70">
              <span>{opened.uploadedBy ?? 'Convidado não identificado'}</span>
              <button
                type="button"
                onClick={() => setOpened(null)}
                className="text-accent-light underline underline-offset-4"
              >
                Fechar
              </button>
            </figcaption>
          </figure>
        )}
      </Modal>
    </>
  )
}
```

```ts
'use server'

import { requireAdmin } from '@/lib/auth/session'
import { listFavoritePhotos, listPhotos } from '@/lib/db/queries/photos'

export async function getDownloadUrls(onlyFavorites: boolean) {
  await requireAdmin()

  const photos = onlyFavorites
    ? await listFavoritePhotos()
    : (await listPhotos({ limit: 5000 })).items

  return photos.map((photo, index) => ({
    url: photo.fullUrl,
    name: `${String(index + 1).padStart(4, '0')}-${photo.uploadedBy ?? 'convidado'}.jpg`,
  }))
```

- [ ] **Step 3: Escrever o botão**

O zip é montado no navegador de propósito: empacotar centenas de fotos numa função serverless estoura o tempo limite, enquanto no navegador não há esse teto e os bytes vão direto do Blob para o disco.

O download é feito em lotes para não segurar centenas de arquivos em memória ao mesmo tempo.

```tsx
// app/(admin)/admin/fotos/DownloadButton.tsx
'use client'

import { downloadZip } from 'client-zip'
import { useState } from 'react'
import { getDownloadUrls } from './download-actions'
import { Button } from '@/components/ui/Button'

const BATCH_SIZE = 25

async function fetchBatch(entries: { url: string; name: string }[]) {
  return Promise.all(
    entries.map(async (entry) => {
      const response = await fetch(entry.url)
      if (!response.ok) throw new Error(`Falha ao baixar ${entry.name}`)
      return { name: entry.name, input: await response.blob() }
    })
  )
}

export function DownloadButton() {
  const [progress, setProgress] = useState<string | null>(null)
  const [error, setError] = useState<string | null>(null)

  async function handleDownload(onlyFavorites: boolean) {
    setError(null)
    setProgress('Preparando...')

    try {
      const entries = await getDownloadUrls(onlyFavorites)

      if (entries.length === 0) {
        setProgress(null)
        setError(onlyFavorites ? 'Nenhuma foto favoritada.' : 'Nenhuma foto enviada.')
        return
      }

      const files: { name: string; input: Blob }[] = []

      for (let index = 0; index < entries.length; index += BATCH_SIZE) {
        const batch = entries.slice(index, index + BATCH_SIZE)
        files.push(...(await fetchBatch(batch)))
        setProgress(`Baixando ${files.length} de ${entries.length}...`)
      }

      setProgress('Compactando...')
      const blob = await downloadZip(files).blob()

      const href = URL.createObjectURL(blob)
      const anchor = document.createElement('a')
      anchor.href = href
      anchor.download = onlyFavorites ? 'fotos-favoritas.zip' : 'fotos-da-festa.zip'
      anchor.click()
      URL.revokeObjectURL(href)

      setProgress(null)
    } catch (downloadError) {
      console.error('Falha no download em lote:', downloadError)
      setProgress(null)
      setError('Não foi possível concluir o download. Tente novamente.')
    }
  }

  return (
    <div className="flex flex-col items-end gap-2">
      <div className="flex gap-2">
        <Button variant="ghost" onClick={() => handleDownload(true)} disabled={progress !== null}>
          Baixar favoritas
        </Button>
        <Button onClick={() => handleDownload(false)} disabled={progress !== null}>
          Baixar todas
        </Button>
      </div>
      {progress && <p className="text-xs text-foreground/70">{progress}</p>}
      {error && (
        <p role="alert" className="text-xs text-danger">
          {error}
        </p>
      )}
    </div>
  )
}
```
